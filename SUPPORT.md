# Support

This is a sample project maintained on a best-effort basis.

- **Questions & bugs** — open a [GitHub issue](../../issues) using one of the
  templates.
- **Feature ideas** — open an issue describing the use case.
- **Security issues** — do NOT open a public issue; see [SECURITY.md](SECURITY.md).

Before filing, please check existing open and closed issues. Include your Node
version, the MCP client you use, and the arguments you passed to the tool.
